## 📖 Tentang

Website portofolio satu halaman yang menampilkan profil, keahlian, dan proyek pilihan —
mulai dari Newsify, Masjid Korea, aplikasi restoran, sampai Weather App. Dibangun dengan
Flutter Web, layout responsif (`responsive_framework`), dan animasi teks.

---

## 🌟 Fitur

- 🖥️ **Layout responsif** untuk desktop, tablet, dan ponsel
- ⌨️ **Animasi teks** dengan `animated_text_kit`
- 🎠 **Carousel proyek** dengan indikator halaman
- 🔗 **Tautan proyek** langsung ke GitHub dan live site
- 📬 **Kontak** lewat `url_launcher`
- 🎨 Tipografi Google Fonts

---

## 🛠️ Tech Stack

| Area | Pilihan |
|---|---|
| Framework | Flutter Web |
| State management | GetX |
| Responsif | `responsive_framework` |
| Animasi | `animated_text_kit`, `carousel_slider` |
| Utilitas | `get_storage`, `dots_indicator` |

---

## 🚀 Menjalankan

```bash
flutter pub get
flutter run -d chrome
```

Build produksi:

```bash
flutter build web
```
